# Excel Data Automation & Automated Report Merger

A Python automation tool designed to process, merge, and clean multiple Excel reports into a single consolidated master sheet.

## Features
- **Automated Directory Scanning:** Scans the designated folder for `.xlsx` and `.xls` files.
- **Data Consolidation:** Merges multiple files into a single master sheet automatically.
- **Data Cleaning:** Detects and removes duplicate entries to ensure data integrity.
- **Scalable:** Handles any number of files with zero manual intervention.

## Tech Stack
- Python 3.x
- Pandas
- OpenPyXL
